# 🐱 Liquid Cat: Battle of Ken

เกม 2D แนว Action / Boss Fighting ที่ผู้เล่นควบคุมตัวละคร **Liquid Cat** เลือก Boss ที่ต้องการต่อสู้ โดยแต่ละ Boss อยู่คนละด่าน และมีสกิลกับรูปแบบการโจมตีที่แตกต่างกันตามแต่ละด่าน

---

## 1. Game Concept

| หัวข้อ | รายละเอียด |
|---|---|
| **ชื่อเกม** | Liquid Cat: Battle of Ken |
| **แนวเกม (Genre)** | Action / Boss Fighting (แอ็กชัน ต่อสู้กับ Boss) |
| **รูปแบบ** | 2D |
| **แนวคิดหลัก** | เลือก Boss เพื่อต่อสู้เป็นด่าน ๆ โดยสกิลของ Boss จะขึ้นอยู่กับด่านนั้น |

---

## 2. Gameplay Loop

### เกมเกี่ยวกับอะไร
ผู้เล่นควบคุม Liquid Cat เลือก Boss / ด่านที่ต้องการ แล้วเข้าไปต่อสู้ ต้องเดิน หลบ โจมตี และหลบสกิลพิเศษของ Boss จนกว่า Boss จะถูกกำจัด

### Flow การเล่น

```mermaid
flowchart TD
    A[เริ่มเกม] --> B[เลือก Boss / เลือกด่าน]
    B --> C[เข้าสู่ด่านของ Boss]
    C --> D[ต่อสู้กับ Boss<br/>- เดินและหลบการโจมตี<br/>- โจมตี Boss<br/>- หลบสกิลพิเศษของ Boss]
    D --> E{Boss HP = 0 ?}
    E -- ใช่ --> F[Boss ถูกกำจัด]
    F --> G[ผ่านด่าน]
    G --> H{กำจัด Boss ครบทุกด่าน ?}
    H -- ใช่ --> I[จบเกม 🎉]
    H -- ยังไม่ครบ --> B
    E -- ยังไม่ใช่ --> J{Player HP = 0 ?}
    J -- ยังไม่ใช่ --> D
    J -- ใช่ --> K[Game Over]
    K --> C
```

### เงื่อนไขการชนะ
- กำจัด Boss ของแต่ละด่านให้ได้
- กำจัด Boss ครบทุกด่าน → **จบเกม**

### เงื่อนไขการแพ้
- HP ของผู้เล่นเหลือ 0 → **Game Over**
- ผู้เล่นสามารถเริ่มด่านใหม่และลองสู้กับ Boss อีกครั้งได้

### จุดเด่นของเกม
Boss แต่ละตัวมีสกิลและรูปแบบการโจมตีแตกต่างกัน ผู้เล่นจึงต้องปรับวิธีการเล่นให้เหมาะกับ Boss แต่ละตัว

## 4. Boss (kendo)

### Boss 1: `final class Teacher` (ด่าน OOP)

| หัวข้อ | รายละเอียด |
|---|---|
| **HP** | 500 |
| **การเคลื่อนที่** | ขยับขึ้นลงอัตโนมัติ ความเร็วปานกลาง (Medium) |
| **สกิลที่ Boss ทุกตัวมี** | ทุก 15 วินาทีจะยิงเลเซอร์ มีเส้นเตือนก่อน 1.2 วินาที ทำดาเมจ 25 (กระโดดหลบได้) |
| **สกิลพิเศษ** | โยนลูกอมหนามใส่ผู้เล่นทุก 3 วินาที ทำดาเมจ 15 |
| **Skill ที่ดรอปเมื่อชนะ** | Candy (OOP) |

### Combat
- โจมตีปกติ (ปุ่ม E): ทำดาเมจ 10 ยิงได้ 5 ครั้งติดกัน แต่ละครั้งห่างกัน 0.5 วินาที แล้วต้องรอคูลดาวน์ 2 วินาที (แสดงเป็นจุด 5 จุดใต้หลอด HP)
- โดนโจมตีแล้วจะเป็นอมตะ 1 วินาที
- HP ผู้เล่นเหลือ 0 = แพ้ ถ้าลด HP ของ Boss จนเหลือ 0 = ชนะ กด **R** เพื่อเริ่มใหม่ (เริ่มใหม่แล้ว skill ที่ได้จะหายไป)

### ไฟล์
- `Boss.java`: คลาสแม่ของ Boss ทุกตัว (การเคลื่อนที่ เลเซอร์ HP)
- `TeacherBoss.java`: Boss ตัวแรก + สกิลโยนลูกอม
- `BossLaser.java`: เลเซอร์ทุก 15 วินาที
- `GameHud.java`: หลอด HP ของ Boss, จำนวนการโจมตีที่เหลือ, หน้าชนะ/แพ้
- `assets/boss/`: รูป Boss และลูกอม
